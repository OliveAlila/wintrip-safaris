# Assets and image rights

`assets/images/wintrip-logo.png` is the Wintrip Safaris logo supplied by the project owner.

The photos currently use Unsplash CDN URLs as visual placeholders selected by subject. They are not claimed to be identical to ViuTravel's photos. Please confirm each image's license and intended use, then replace remote placeholders with authorized, optimized local images before launch. Do not scrape/reuse another operator's image files without permission.
